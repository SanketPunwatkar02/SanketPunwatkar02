### 🖥️ PC Monitoring System
> Real-time PC fleet tracking & status dashboard

**Problem:** No lightweight, self-hostable tool to monitor lab/office PCs in real time.

**Solution:** Full-stack system with hardware-based unique device identification, live Active / Idle / Offline tracking, and a centralized dashboard.

**Tech:** `Node.js` `Express` `MongoDB` `React` `Render`

**Highlights:**
- ⚡ Real-time status updates via polling
- 🔐 Hardware fingerprint-based device ID
- ☁️ Backend deployed on Render
- 📊 Designed for scale & automation
